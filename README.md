# TravelTrucks — Camper Rental Platform

Веб-застосунок для пошуку та бронювання кемперів. Побудований на Next.js (App Router) з TypeScript.

## Стек технологій

- **Next.js** (App Router) — фреймворк, маршрутизація
- **TypeScript** — типізація
- **TanStack Query** (`useQuery`, `useInfiniteQuery`, `useMutation`) — робота з даними бекенду, пагінація
- **Axios** — HTTP-клієнт
- **Swiper** — галерея зображень кемпера (thumbs gallery)
- **CSS Modules** — стилізація
- **react-hot-toast** — нотифікації

API: [`https://campers-api.goit.study`](https://campers-api.goit.study)

## Встановлення та запуск

```bash
git clone <repo-url>
cd <project-folder>
npm install
```

Створити файл `.env.local` у корені проєкту:

```env
NEXT_PUBLIC_API_URL=https://campers-api.goit.study
```

Запуск для розробки:

```bash
npm run dev
```

Продакшн-білд:

```bash
npm run build
npm run start
```

## Сторінки застосунку

| Маршрут | Опис |
|---|---|
| `/` | Домашня сторінка з банером і кнопкою переходу в каталог |
| `/catalog` | Каталог кемперів зі списком, фільтрами та пагінацією Load More |
| `/catalog/[camperId]` | Сторінка деталей кемпера — галерея, опис, характеристики, відгуки, форма бронювання |

## Функціональність

### Домашня сторінка (`/`)
- Банер з основним закликом до дії
- Кнопка переходу на сторінку каталогу

### Каталог (`/catalog`)
- Список кемперів, отриманих із бекенду
- Фільтрація на бекенді через query-параметри:
  - `location` — текстове поле
  - `form` — тип кузова (один варіант)
  - `engine` — тип двигуна (один варіант)
  - `transmission` — тип трансмісії (один варіант)
- Динамічне отримання допустимих значень фільтрів з `/campers/filters`
- Пагінація у форматі **Load More** через `useInfiniteQuery` (довантаження по 4 картки, з урахуванням активних фільтрів)
- Кнопка **Show more** на кожній картці — відкриває сторінку деталей у новій вкладці
- Стан "нічого не знайдено" (Empty State) з кнопками скидання фільтрів

### Сторінка деталей кемпера (`/catalog/[camperId]`)
- Повна інформація про кемпер (назва, ціна, рейтинг, локація, опис, характеристики)
- Галерея зображень через Swiper (основний слайдер + мініатюри)
- Відгуки користувачів з п'ятизірковою шкалою оцінок
- Форма бронювання (ім'я, email) з власною валідацією
- Нотифікація про успішне бронювання після відправлення форми
